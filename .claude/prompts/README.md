# Prompts

Copy-paste prompt templates for this project. Unlike a skill or agent, nothing here
auto-runs — open a file, copy its prompt block, fill in the `<...>` blanks, paste into
chat.

- [add-component.md](add-component.md) — scaffold a new standalone component
- [add-primeng-feature.md](add-primeng-feature.md) — build a feature with PrimeNG
- [add-ag-grid-table.md](add-ag-grid-table.md) — add an AG Grid Enterprise table
- [write-tests.md](write-tests.md) — write Vitest tests for a file
- [pre-push-check.md](pre-push-check.md) — run lint + test before pushing
- [mock-api-setup.md](mock-api-setup.md) — point dev environment at the mock API

Add a new `.md` file here for each new reusable prompt, and list it above.
